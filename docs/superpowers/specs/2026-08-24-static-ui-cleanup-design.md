# 静态 UI 清理与统一布局

## 目标

在不移除现有教程、导航、歌词窗、工具栏、社群、视频、案例和下载资源的前提下，删除已废弃的视觉与交互代码，并将页面收敛为统一的深色静态教程站。

## 保留

- 顶部导航与首屏行动按钮。
- 四步教程及其逐步切换、复制、展开与跳转功能。
- 可暂停、选句、拖动的首页寄语窗口。
- 本地优化、工具栏、视频、社群、案例、GitHub 区块及现有下载资源。

## 删除

- 未挂载的小球、流体、水波、烟花画布及其事件、循环与样式。
- 音乐、亮色主题及对应历史选择器。
- 已无对应 DOM 的过期样式、重复动画、覆盖链和媒体查询。

## 布局规范

- 全站单一 `1120px` 居中容器，移动端缩为单列。
- 首屏采用左侧内容、右侧寄语窗；不使用绝对漂移以外的装饰性区域。
- 后续模块按固定垂直节奏排列，标题、说明、卡片、按钮使用同一间距和颜色令牌。
- 卡片只用于信息分组；步骤使用分隔线和编号，避免大面积空白与无意义阴影。

## 验收

- 页面无背景画布、音频或主题切换残留。
- `src/main.js` 不再包含画布渲染函数与监听器。
- CSS 不再包含 `#heroCanvas`、`#mainCanvas`、`#fluidCanvas`、`#musicToggle`、亮色主题规则。
- 现有单元测试、语法检查、差异空白检查通过；安全扫描若受 Windows 编码问题阻塞，记录原因。
